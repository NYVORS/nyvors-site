# NYVORS website

Static landing page for NYVORS and its first project, MetroRed.

## Files
- `index.html` — page content
- `styles.css` — responsive styling
- `script.js` — small navigation enhancement
- `assets/nyvors-logo.png` — provided NYVORS logo

## Deploy with GitHub Pages
1. Create a GitHub repository (for example `nyvors-site`).
2. Upload all files and folders from this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish and copy the public URL.

The site is static and does not require a build step.
